# StellarPulse.

StellarPulse: Cosmic Audio Visualizer & 1080p Recorder
StellarPulse is a lightweight, high-performance web application that transforms your favorite music into an immersive, deep-space visual experience. Featuring a dynamic circular audio waveform surrounded by a reactive starfield and particle mesh tunnel, it syncs breathtaking visuals directly to the frequencies of your audio.

Whether you're looking to enjoy a mesmerizing desktop background companion for your study sessions or create high-definition music videos, StellarPulse delivers.

Key Features
Real-Time Frequency Analysis: Powered by the Web Audio API to render responsive visual pulses, glowing nebulas, and ring particles that react dynamically to beats.

Built-in 1080p Video Recording: Capture your custom visualizer sessions in full HD (1920x1080) using an off-screen canvas stream recorder, complete with merged audio tracks ready for instant download.

Dual Audio Modes: Upload any local audio file (MP3, WAV, OGG, AAC) via drag-and-drop or file selector, or instantly test the visualizer using the built-in live frequency demo synthesizer.

Bilingual Support: Fully localized interface with seamless switching between Persian (Farsi) and English, complete with RTL/LTR layout management.

Modern Glassmorphism UI: Built with Tailwind CSS, custom CSS backdrop filters, and FontAwesome icons for a sleek, futuristic aesthetic.
